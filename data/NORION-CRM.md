## 1. Как читать связи

```
ПРОЕКТ
  └─ ВОЛНА A / B / C          (срок открытия)
       └─ ЗОНА                (Corner, кухня, зал…)
            └─ ЗАДАЧА         (код NOR-xxx)
                 ├─ отвечает СОТРУДНИК
                 ├─ направление работы
                 ├─ зависит от других ЗАДАЧ
                 └─ готово когда = критерий закрытия
```

Правило закрытия задачи: не «поставили галочку», а выполнен текст в колонке «готово когда».

## 5. Продукт (чтобы задачи не разъехались)

**Corner / амстердамские вафли**  
Пекут вафлю → режут → внутрь карамель → снаружи шоколад → посыпка (сублимированные ягоды, зефир, шоколад, M&M).  
Не «вафля с топпингом сверху».  
4 лица на старт: Classic / Berry / Party / Soft.  
Эталон: 10 минут в коробке без течи. Выдача **только в уличное окно**. Внутреннее окно — в январе, в Fan Zone.

**Кухня / 3 облачных бренда**  
Бургеры / пельмени своей лепки / обед весь день.  
Пельмени: замес → лепка → заморозка → варка → 25 мин в коробке. Не live под заказ.  
2 агрегатора. 3 юр.витрины. Адрес выдачи курьеру — служебка, не окно вафель.

**Зал**  
Европейское короткое 12–16 + завтрак с той же кухни. Алкоголь да. Те же 3 повара.

## 8. Критический путь к каждой дате открытия

До **10 октября (окно)** нельзя опоздать:  
001 → 003 → 008  
002 → 006 → 008  
004 → 007 → 011 → 014 → 015  
005 → 014  
009, 010, 012 → 014 → 015

До **31 октября (доставка)** нельзя опоздать:  
016 → 017 / 018 / 020 → 022  
019 → 022  
018 → 021 → 022  
022 держит старт ремонта зала (025).

До **10 января (зал)** нельзя опоздать:  
022 → 025 → 026 / 033  
023 → 025  
024, 027, 028 → 035

Можно сдвигать без срыва даты: 013, 029, 030, 031, 032, 034.

## 9. Чего в выгрузке нет

- Пустые базы Notion «Закупки» и «Оборудование» — отдельных SKU и счетов не было.
- Старые черновики с гостевым туалетом на волне A и «бариста на октябрь» — вычищены, сюда не входят.
- Клиенты / лиды / касса — этого в CRM X не было.

Импорт в CRM: одна сущность «Задача» (NOR-001…035), связанные справочники «Люди» (P-*) и «Зоны» (Z-*). Поле `depends_on` = список id из блока 6.
