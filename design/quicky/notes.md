# Quicky — личный штаб с агентами (v2)

Открыть: в этой папке `python3 -m http.server`, затем http://localhost:8000.

## Референс
Kin — AI Family Care (Pinterest, 6 слайдов). Взято:
- пастельное небо (голубой → сиреневый → розовый) и белые карточки;
- главная цифра тонким весом на тёплой персиковой карточке с полосами;
- AI-подсказка в голубой рамке + «тянучка» дней (таблетки с перемычками);
- голубая кнопка с тёмным текстом и иконкой в белом квадрате;
- «семья» → агенты: аватары в скруглённых квадратах;
- «Up next» → «Дальше»: полоска-градиент слева, время справа, голубое свечение снизу;
- вертикальная бледно-голубая рейка + отдельный круглый поиск.

## Агенты
| Агент | Роль | Источник |
|---|---|---|
| @bari | глава штаба, приоритеты, черновики ответов | всё сразу |
| @kassa | оплаты | Google Sheets |
| @crm | задачи, сроки, стадии | CRM X API |
| @pochta | почта | mail.ru (IMAP) |
| @tg | чаты и упоминания | Telegram |

Обратиться: кнопка агента, ⌘K, или `@имя` в начале сообщения — разговор сам переключится.
Агенты только читают и предлагают; отправку и оплату делает человек.

## Бренд
- `logo.svg` — Q: горизонтальный овал + диагональ, выходящая хвостом вправо-вниз.
- `logo-lockup.svg` — знак + «quicky» (Onest Medium, трекинг −1.6).
- `icon.svg` / `icon-512.png` — иконка macOS: пастельный squircle, знак чернилами.
- Шрифт Onest 300/400/500/600; цифры — 300.

## Проверено
375 / 768 / 1440 px без горизонтального скролла; контраст ≥ 4.5:1 (кнопка 9.5:1);
окно агента: открытие, переключение через @, Esc, возврат фокуса; консоль чистая.

## Не сделано
Ответы агентов заготовлены (демо). Разделы рейки — заглушки. Нет экрана «Новый агент».
