# CRM X

Операционная система запуска пространства в Ереване (кинотеатр «Москва»): задачи, проекты, команда, roadmap.

**Прод:** [crm-x-nine.vercel.app](https://crm-x-nine.vercel.app)

Это не sales-CRM. Волны запуска A / B / C, проекты **WAFL · Kitchen · CAFE · COMX**.

## Что умеет

- Главная: дата, рассылка Owner, плитки готовности проектов, кольца, задачи дня, roadmap
- Доски канбан: **Не начато · бэклог** → **В работе** → **На проверке** → **Готово**
- Карточка задачи: описание, чеклист, вложения, комментарии с эмодзи, critical path
- Уведомления: новые яркие, прочитанные серые, исчезают через 4 дня
- Wiki и контакты (телефон / Telegram / WhatsApp)
- Команда: роли, доски, руководитель (сотрудник видит свои задачи и задачи подчинённых)

## Кто видит что

| Роль | Доступ |
| --- | --- |
| Owner (`1111`) | всё |
| Armen (`2222`) | команда, их задачи |
| Сотрудник | только назначенные ему задачи и задачи тех, у кого он руководитель |

Пароль = логин (`1111`…`9999` в демо).

## Стек

- Next.js (App Router) в папке `web/`
- Состояние в браузере + опционально Aiven Postgres
- Деплой: Vercel, root directory = `web`

## Локально

```bash
cd web
npm install
npm run dev
```

Открыть [http://localhost:3000](http://localhost:3000).
