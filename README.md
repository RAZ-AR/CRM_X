# CRM X

Операционная система запуска пространства в Ереване (кинотеатр «Москва»): master-план, задачи, команда, roadmap.

**Прод:** [crm-x-nine.vercel.app](https://crm-x-nine.vercel.app)

Это не sales-CRM. Проекты: **WAFL · Dark Kitchen · CAFE · COMX · ОБЩИЕ** (юрлица, бухгалтерия, демонтаж, общие вопросы).

## Master-план (старт 24.09.2026)

| Проект | Открытие |
| --- | --- |
| 🧇 WAFL (+ Telegram Mini App с лояльностью и геймификацией) | **28.10.2026** |
| 🍳 Dark Kitchen | **10.11.2026** |
| 📚 COMX | 15.12.2026 (ориентир) |
| ☕ CAFE | 15.01.2027 (ориентир) |

Ремонт строго по очереди: WAFL → Dark Kitchen → COMX → CAFE. В каждом: демонтаж → замер → планировка → дизайн → согласование → ремонт.

Весь план: [`data/master-plan.csv`](data/master-plan.csv), 173 задачи с датами, результатом, исполнителем и зависимостями. Правится в [`web/scripts/master-plan.py`](web/scripts/master-plan.py), затем `python3 web/scripts/master-plan.py` пересобирает сид и CSV.

**7 потоков:** LEGAL · SPACE · BRAND · PRODUCT · EQUIPMENT & SUPPLY · PEOPLE · LAUNCH. Готовность проекта и каждого потока считается автоматически из закрытых задач: обычная весит **1**, critical path **3**.

## Что умеет

- Главная: обратный отсчёт до открытий, рассылка Owner, roadmap по основным вехам (демонтаж → … → открытие), плитки проектов, задачи дня
- Доски канбан: **Не начато · бэклог** → **В работе** → **На проверке** → **Готово**
- Карточка задачи: результат «готово когда», чеклист, вложения, комментарии, зависимости, critical path
- Проект: готовность по 7 потокам
- Уведомления, Wiki, контакты, команда

## Кто видит что

| Логин | Роль | Доступ |
| --- | --- | --- |
| `Armen` | Owner проекта | всё; редактирует и удаляет любые задачи; управляет командой |
| `Vladimir` | Креативный директор | свои задачи и задачи Karina (руководитель) |
| `Karina` | Маркетинг | свои задачи |

Редактировать и удалять задачу может Owner (любую) или её автор. Исполнитель меняет статус, чеклист, пишет комментарии.

Стартовые пароли выдаёт Owner. Каждый может сменить свой пароль сам: меню → **Мой профиль**. Логин не чувствителен к регистру.

## Стек

- Next.js (App Router) в папке `web/`
- Общий стейт в Vercel Blob (+ опционально Aiven Postgres)
- Деплой: Vercel, root directory = `web`

## Локально

```bash
cd web
npm install
npm run dev
```

Открыть [http://localhost:3000](http://localhost:3000).
